## 1. 結論サマリー

- **21期の採用目標は17名**（外勤営業15名＋反響・インサイドセールス新設2名）。期中離職を7名と保守的に見込み、期末に**外勤営業33名＋IS2名＝営業組織35名体制**を作る。これで180棟（1人あたり年6棟×期中平均稼働29名＝174棟±）を達成する。
- **実行予算は4,205万円**（採用直接費1,325万＋SNS・ブランディング600万＋採用体制強化600万＋定着投資880万＋28卒先行投資800万）。**予算上限7,500万円に対し3,295万円を戦略予備費**として保持し、上期実績を見て投下判断する。1名あたり採用単価は直接費ベース78万円（全業種平均103万円を下回る）。
- 直近の**離職率24%（6名以上/25名）は本計画最大のリスク**。この水準が続くと「採っても埋まらない」ため、定着投資（90日オンボーディング・メンター・初年度ミニマム保障）を採用と同格のKPIで管理し、**21期離職を4名以下（15%以下）**に抑える。
- SNS（TikTok・Instagram・YouTube×2）は媒体別に役割を固定し、**年間投稿204本・SNS起点応募を全応募の30%（月4件）**まで引き上げる。
- 法令上「20代男性限定」の募集は不可。**年齢は「35歳未満・経験不問・長期育成」（例外事由3号のイ）で合法的に限定**し、性別は訴求・チャネル設計で実質的に寄せる（詳細は調査資料第2章）。

## 2. 人員計画：採用17名・期末35名体制

### 2-1. 逆算根拠

```
180棟 ÷ 6.0棟/人（20期実績: 150棟÷25名） ＝ 30名が通年フル稼働で必要
新人の立ち上がり（入社後6か月は0.5人力）を織り込み、期末33名まで積み上げる
```

| 項目 | 数値 | 備考 |
|---|---|---|
| 期首在籍（2026/9/1） | 25名 | |
| 期中離職想定 | ▲7名 | 直近実績24%を踏まえ28%で保守設定（目標は4名以下だが計画は7名で組む） |
| 外勤営業 採用 | **＋15名** | 中途11名＋新卒（2027年4月入社）2名＋退職自衛官2名 |
| 期末外勤営業 | **33名** | |
| 反響・IS職 採用（新設） | **＋2名** | 反響一次対応・アポ設定専任。未経験の入口職種（セールスフォース型） |
| **期末営業組織 計** | **35名** | |

- 期中平均稼働は約29名（新人0.5人力換算で約27人力）→ 27人力×6.5棟（IS支援による外勤の商談集中効果込み）≒ **176〜182棟**。180棟目標と整合。
- **IS職2名の意味**: ①反響対応の速度向上（機会損失削減）、②外勤営業を商談・クロージングに集中させ1人あたり棟数を6.0→6.5棟へ、③「いきなりフル営業は怖い」層の採用入口（成果で外勤へ昇格）。

### 2-2. 採用17名の内訳

| 区分 | 人数 | 入社時期 | 想定年齢層 |
|---|---|---|---|
| 中途・未経験可（他業界若手営業・接客出身等） | 9名 | 2026年10月〜2027年6月に分散 | 23〜32歳 |
| 中途・不動産/住宅経験者 | 2名 | 通年（出会い次第） | 25〜34歳 |
| 新卒（27卒・秋採用） | 2名 | 2027年4月 | 22〜23歳 |
| 退職自衛官（任期満了） | 2名 | 2027年3〜4月 | 24〜31歳 |
| 反響・IS職（未経験可） | 2名 | 2026年11月・2027年2月 | 21〜28歳 |
| **計** | **17名** | | |

## 6. SNS・広報計画

### 6-1. ファネル設計（役割の固定）

```
[認知]           [興味・親近感]        [理解・確信]               [応募・承諾]
TikTok(週3) → Instagram(週2+3) → YouTube会社CH(月2)      → 採用サイト/ピッチ資料
                                  社長CH(月1)               チアキャリア/エージェント
```

候補者は面接前に必ずSNSと口コミを見る（Z世代の行動データは調査資料§3-4・§6-2）。SNSは応募獲得装置であると同時に**選考辞退・内定辞退・親ブロックを防ぐ装置**として運用する。

### 6-4. 制作・運用体制（週次サイクル）

- **週次ネタ会議30分**（人事＋若手営業2名輪番）: 翌週の撮影ネタ決定。営業現場の「今週あったこと」を吸い上げ。
- **撮影は週1回2時間にまとめ撮り**（TikTok3本＋IG素材）。編集は外注（月30万円枠）。
- **月次KPIレビュー**（§6-2の数値目標に対する実績。応募フォーム「知ったきっかけ」集計とセット）。
- **出演者ガイドライン**: 顧客・物件特定情報の映り込み禁止／給与言及は実績ベース・誇張禁止（平均とトップの区分必須）／「男性向き」等の均等法NG表現禁止／退職者映像は本人同意のみ。

## 7. 選考プロセスSLAとファネルKPI

### 7-1. 選考SLA（Service Level Agreement）

| ステップ | SLA | 責任者 |
|---|---|---|

| 指標 | 年間 | 月平均 | 転換率目標 |

## 8. 定着計画：離職6名→4名以下へ

**直近の離職率約24%は、採用17名の努力を半分無効化する水準**（半年以内離職1名の損失≒640万円。7名なら理論上▲4,480万円相当）。21期は以下を採用と同格のKPIで実行する。

| 施策 | 内容（数値確定） | 予算 | 目標 |
|---|---|---|---|
| 90日オンボーディング | 入社→30日（同行・商品/ローン基礎）→60日（反響対応独り立ち）→90日（初契約支援）。各節目で人事面談30分 | 運用工数のみ | 90日定着率95% |
| メンター制度（カネテツ式） | **直属上司以外**の先輩をメンター任命。毎月1回目標設定→月末フィードバック。メンター手当**月1万円** | 180万円/年 | メンター面談実施率100% |
| 初年度ミニマム保障 | 未経験入社者は入社12か月間、歩合ゼロ月でも**月5万円の調整手当**で下支え（大東建託・特別加算手当方式の当社版） | 480万円/年（8名分） | 「収入不安」起因離職 0件 |
| 評価の透明化 | 歩合・昇進基準を数式で全社開示（キーエンス型）。「時間でなく成果」を評価基準に明文化 | 0円 | ー |
| 離職の資産化 | 退職面談の定型化（原因をコード化して四半期集計）／円満退職者はアルムナイ登録・紹介者化 | 0円 | 離職原因データの蓄積 |
| 口コミ対策 | OpenWork・転職会議・エン カイシャの評判を**四半期モニタリング**。在籍社員の自発的レビューを依頼（操作はしない） | 40万円/年（§4-B内） | 総合スコアの維持向上 |

**21期の離職目標: 4名以下（15%以下）**。達成すれば22期は「採用12名で40名体制」が視野に入り、採用予算を約25%圧縮できる。

## 10. リスクと撤退基準

| リスク | 兆候（数値トリガー） | 対応 |
|---|---|---|
| 応募が集まらない | 3か月連続で月次応募10件未満 | 予備費からSNS広告ブースト＋媒体追加（Re就活38万円/4週〜）。原稿・ピッチ資料のA/B改訂 |
| 承諾率が低い | 承諾率60%未満が2四半期 | 内定者フォロー強化（社長面談前倒し）・給与提示方法の見直し・辞退理由の全件ヒアリング |
| 離職が止まらない | 期中離職が2月末時点で4名超 | **採用の追加投下より定着投資を優先**（予備費から研修・処遇改善へ。採り続けて埋める発想を取らない＝光通信の教訓） |
| エージェント供給不足 | ②のチャネルで12月末までに2名未達 | 上位実績社へ集中＋紹介料率の一時引き上げ（85万→100万円）を予備費で対応 |
| 予備費の扱い | ー | **上期レビュー（2026/12）で投下可否を判断。使い切りは目的にしない。**未執行分は22期繰越または利益還元 |
| 法令・炎上 | ー | §6-4ガイドライン＋全求人原稿の社労士チェック（調査資料§2のNG/OK表参照）。SNS炎上時は即時非公開→事実確認→24時間以内に対応方針決定 |
