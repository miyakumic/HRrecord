## 1. 計画の考え方

### 1-1. 逆算ロジック

```
21期 必要営業人員 ＝ 21期 供給棟数目標 ÷ 1人あたり年間販売棟数
21期 採用必要数   ＝（必要営業人員 − 期首在籍）＋ 期中離職想定数
```

- 現状「年間約150棟」を営業25〜35名で販売していると仮定すると、**1人あたり年間4〜6棟**が生産性の目安。
- 離職想定は業界データから置く：大卒3年以内離職率は全国33.8%（年約10%ずつ）、不動産業界は高止まり。**期中離職率15%（保守的）〜10%（定着施策が効いた場合）**で計画する。
- 調査資料の教訓（オープンハウス平均勤続4.5年、光通信の反面教師）より、**「多めに採って辞めさせる」計画は組まない**。半年以内離職1名の損失は約640万円（エン・ジャパン試算）であり、定着率を計画のKPIに含める。

### 1-2. 21期の基本方針（調査資料からの反映事項）

1. **属性限定ではなく設計で寄せる**: 「20代男性限定」は違法。当社の実績訴求（20代で1,000万円・平均年齢27歳・未経験90%）＋チャネル選定（体育会・自衛官・20代特化）で、結果として上昇志向の若手が集まる設計にする。
2. **成功報酬型チャネル中心**: 社員約50名の企業が掲載課金で大手（オープンハウス初任給40万円等）と正面勝負しない。採れなければ費用ゼロの構造を基本にする。
3. **「見える化＋スピード」の徹底**: 給与実例の年次別公開、応募当日連絡、1週間以内内定。
4. **SNSは「採用ファネルの装置」として役割分担**: 各媒体をバラバラに運用せず、認知→興味→確信→応募の役割を固定する（第5章）。

## 5. SNS・広報：媒体別の役割と打ち出し方向性

### 5-1. 全体設計：ファネルで役割を固定する

当社はすでに **TikTok・Instagram（@tokyobighouse_saiyou、人事運用）、YouTube会社チャンネル、社長チャンネル、Notion採用ページ、チアキャリア** を保有している。21期はこれらを「個別に頑張る」のではなく、**候補者が応募前後に辿る順番**に沿って役割を固定する。

```
[認知]        [興味・親近感]      [理解・確信]              [応募・承諾]
TikTok   →   Instagram    →   YouTube（会社CH）      →   採用サイト/ピッチ資料
                              社長チャンネル              チアキャリア/エージェント経由
```

- 調査資料の知見：Z世代は広告より「働く人のリアル」と口コミを信頼し（2023卒の82%がTikTok毎日利用、TikTok経由で興味→66%が応募）、**面接前に必ずSNSと口コミを見てから来る**。つまりSNSは「応募を獲る装置」であると同時に「選考辞退・内定辞退を防ぐ装置」。
- 各媒体のコンテンツは第5-3のメッセージ標準から作る（媒体ごとに言うことを変えない。「見せ方」だけ変える）。

### 5-2. 媒体別の役割・打ち出し方向性・KPI

#### ① TikTok（@tokyobighouse_saiyou）— 役割：認知の入口（ファネル最上流）

| 項目 | 内容 |
|---|---|
| ターゲット | 就活生・第二新卒・現職に不満のある20代前半（まだ当社を知らない層） |
| 打ち出し方向性 | **「不動産営業のイメージを裏切る明るさ・等身大」**。①若手社員の1日密着ショート、②社内ノリ・上司と部下の距離の近さ（リンクロノヴァが応募3倍にした型）、③「20代で年収◯◯万円のリアル」切り抜き、④営業の失敗談・あるある。凝った編集よりテンポと人柄 |
| 頻度 | 週2〜3本（月10本前後） |
| KPI | 再生数→プロフィール遷移数→採用サイトへのリンククリック。四半期で「面接で『TikTok見ました』と言った候補者数」を計測 |
| 注意 | 給与ネタは誇張禁止（平均とトップを明示区分）。「男性向き」等の表現NG。出演者ガイドライン必須 |

#### ② Instagram（@tokyobighouse_saiyou）— 役割：興味の受け皿・応募直前の「身元確認」先

| 項目 | 内容 |

| 頻度 | フィード週1〜2、ストーリーズ週2〜3 |
| KPI | フォロワー数より**保存数とプロフィールからのサイト遷移**。内定承諾率への寄与（承諾者アンケート） |

#### ③ YouTube 会社チャンネル（@tokyobighouse4308）— 役割：理解・確信の形成（面接前後の必視聴コンテンツ）

| 項目 | 内容 |

### 5-4. 制作・運用体制

- **週次30分のネタ会議**（人事＋若手営業1〜2名輪番）：翌週分の撮影ネタ決定。営業現場の「今週あったこと」を吸い上げる。
- **月次KPIレビュー**：媒体別の再生・遷移・応募貢献（応募フォームに「当社を知ったきっかけ」必須設問を追加して計測）。
- **出演者ガイドライン**：顧客情報・物件特定情報の映り込み禁止、給与言及ルール（実績ベース・誇張禁止）、退職者映像の扱い。
- 外部支援（編集代行等）は月10万〜30万円の範囲で必要箇所のみ。**企画と出演は内製が原則**（外注すると「等身大」が死ぬ）。

|---|---|---|
| 応募・スカウト返信 | **当日中に連絡** | 8割の企業がスピード起因の辞退を経験→速さ自体が差別化 |
| カジュアル面談 or 一次面接 | 応募から3日以内 | ピッチ資料・動画は事前送付し、当日は対話に集中 |
| 現場同行・トップセールス面談 | 一次から4日以内 | 「仕事内容ミスマッチ」（早期離職要因1位57%）をここで潰す |
| 内定 | **応募から7日以内** | 条件は年収レンジ＋実例で提示 |
| 承諾までのフォロー | 週1接点 | 社長面談・若手ランチ・家族向け資料（承諾率50%→80%事例の型） |

## 7. 定着計画（採用計画と不可分）

採用数を増やすほど定着が計画の成否を決める（半年離職1名≒▲640万円）。

1. **90日オンボーディング・プログラム**: 入社→30日（同行中心・商品/ローン基礎）→60日（反響対応の独り立ち）→90日（初契約支援）。各節目で人事面談。
2. **メンター制度（カネテツ式）**: 直属上司**以外**の先輩をメンターに任命し、毎月目標設定→月末フィードバック。メンターには手当（月5千円〜1万円）。
3. **初年度の収入下支え**: 未経験入社者の初年度は固定給比率を高める or ミニマム保障（大東建託の特別加算手当方式）。歩合の怖さが応募と定着の最大の敵。
4. **評価の透明化**: 歩合・昇格基準を数式で開示（キーエンス型の「わかりやすさ」）。「時間でなく成果」の評価を明文化。
5. **退職時の資産化**: 円満退職者はアルムナイ登録・紹介者化（出戻り歓迎の明文化）。
