## 1. なぜ内定者研修をやるのか(目的)

> 入社してからの導入をスムーズにし、人間的な拡大をさせ、当社で活躍する人材の素養を満たすように育てる。

これを当社の言葉に翻訳すると、入社時導入研修の目的原文——「TOKYO BIG HOUSE社員である自覚と、当社で結果を出して夢を実現するという覚悟を持つ」「『行動量』『やり切る』の当たり前のレベルをTBHの基準に合わせる」——**の到達時期を、入社後6週間から内定期間の6か月へ前倒しする**こと。

### 背景にある3つの経営事実

| 事実 | 内定者研修への含意 |
|---|---|
| **2030年 源泉だけで100億・360棟、2035年 555億・1,850棟**のビジョン(課長10人が必要) | 幹部候補の育成開始を最も早い接点=内定期間から始める |
| **今後、採用基準はさらにゆるくなる**(母集団拡大優先) | 入口で見極めきれない分を、研修で「育てて・見極めて・補正する」。研修が採用基準の一部になる |
| 直近の**離職率24%**、半年以内離職1名≒▲640万円 | ミスマッチの発見と覚悟の醸成は入社前が最も安く済む。入社後の早期離職を内定期間で予防する |

### 内定者研修が同時に果たす5つの機能

1. **導入の前倒し**: 入社日に「TBHの学び方・考え方・習慣」が既に身についている状態を作り、入社後6週間を営業実践に集中させる
2. **人間的な拡大**: 3つの自立(経済的・精神的・自律)、自責、素直さ・アンラーニング——「才よりも姿勢」の土台を作る
3. **活躍素養の育成と可視化**: 活躍人材の共通素養(§3)に特化して鍛え、出席・提出物・テスト・実戦での伸びを記録して配属・育成計画(BQコンポジット分析)に接続する
4. **辞退防止と覚悟の醸成**: 社長・先輩・同期との接点を高頻度で持ち、家族にも説明できる状態を作る。同時に、覚悟が持てない内定者には入社前に気づかせる(お互いの不幸の予防)
5. **28卒採用の戦力化**: 内定者6名が**自分で会社説明会をできる状態**まで育て、28卒採用の説明会登壇・座談会・SNS出演を担ってもらう。あわせて紹介採用(SSC)を内定者にも展開(友人・後輩・サークル・ゼミの紹介)。「TBHを人に語り勧める」こと自体が最強の理念浸透であり(教えることは二度学ぶ)、自分で勧めた会社は辞退しにくいというコミットメント効果で機能4も強化される。21期計画の「内定者×若手コラボ(親ブロック対策)」「27新卒説明会への内定者ゲスト招待」「28卒母集団形成」と直結

## 2. 設計思想(ビジョン経営×営業組織拡大 9社調査より)

オープンハウス、プルデンシャル生命、レバレジーズ、武蔵野、サイバーエージェント、ネクステージ、TERASS、リクルート、キーエンスの事例調査から、当社に適用する原則を5つに絞る。

1. **社長が直接語る**(レバレジーズ/武蔵野型): 50名規模の最大の武器。初回と修了回は必ず社長。創業ストーリー(10代で家を買えなかった悔しさ→すべての人に可能性を提供する不動産営業)から555億ビジョンまでを1本の線で語る
2. **「稼ぐ」を理念の中で規定する**(プルデンシャル「Winning with Integrity」型): 「住まいを通して人が持つ大きな可能性に貢献」×「20代で年収1,000万」×「社会に歓迎されながら555億」を接続した"TBHの勝ち方"を第1回で定義し、全回の背骨にする。コンプライアンス・ゴシップ禁止もこの文脈で教える
3. **入社前に実戦と小さな成功体験**(オープンハウス型): 全員が源泉活動を体験する対面日を設ける。「源泉はパワーの源」「逆張り」の意味は現場でしか腹落ちしない
4. **浸透は反復の儀式で起こる**(武蔵野型): 1回の名講義より、毎回同じ型(予習動画→ワーク→理解度テスト→200字報告→表彰)の反復。経営方針勉強会・導入研修と同じ型を使い、入社前から「TBHの学び方」に慣れさせる
5. **教え込むより気づかせて出力させる**(リクルート/ネクステージ型): 毎回アウトプット(発表・報告・ロープレ)で終える。初回に「入社の目的・人生の目標(日付・予算つき)」を自分で言語化させ、以後全回でそこに立ち返る

## 3. 何を鍛えるか——活躍人材の素養5つ(仮説・要壁打ち)

既存資料(TBHの考え方1〜20、源泉営業心得、経営方針勉強会の講話・解答例、各スタッフ課題)から抽出した活躍素養の仮説。**社内のトップ社員・離職者データと突き合わせて確定させたい。**

| # | 素養 | 社内の言葉 | 主に鍛える回 |
|---|---|---|---|
| 1 | 素直さ・アンラーニング | 「結果にこだわるのが最も素直」「自分の否定はチャンス」「プライドという言い訳」 | 全回の報告・FB文化そのもの |
| 2 | 自責・全責 | 「他人のせいにした瞬間、成長は止まる」「自己責任」 | TBHの考え方⑧〜⑬、7つの習慣(影響の輪) |
| 3 | 目標必達・決める力 | 「目標完全必達主義」「目標達成する人=決める人」「感情ではなく目標が自分」 | 目標設定回、社長セッション、振り返り習慣 |
| 4 | 行動量とやり切り | 「行動量・やり切るの当たり前レベルをTBH基準に」「源泉はパワーの源」 | 実戦対面日、宅建学習の完遂管理 |
| 5 | 集団成功主義の人間性 | 「個人が目標達成し、その結果会社の目標が達成される」「SSC=人間力」「ゴシップ禁止」 | 集団成功主義回、同期ワーク、Best回答賞 |

**採用基準がゆるくなるほど、1(素直さ)と4(行動量)の比重が上がる**——地頭や営業適性は入口で揃わなくなるが、素直に学び行動量を出す人材は研修で作れる、という設計判断。

## 4. 全体構造——25回の骨格

### 4-1. 形式(人事確認済みの方針)

| 項目 | 決定方針 |
|---|---|
| 対象 | **27卒内定者6名**から開始、**28卒以降の5〜10名規模でも同じ設計で回る汎用プログラム** |
| 期間・密度 | 内定承諾後〜入社前(想定10月〜3月・約6か月)、**高密度**(週1オンライン+月1対面) |
| 形態 | **オンライン中心(週次60〜90分)+月1回の対面日**(実戦・社長回・ワークを集約) |
| 実戦 | **全員が源泉活動体験・現場同行をカリキュラム内で経験** |
| 負荷 | **段階的に引き上げ**: 序盤=つながり重視で軽く→中盤から理解度テスト・200字報告など社内同等へ |
| 導入研修との分担 | **ハイブリッド**: 基本はマインド・習慣・知識の前提づくり。終盤5回程度は営業スキルの入口(基本のトーク・ロープレ体験)まで |
| BQ適性検査 | 序盤に受験+FB回を実施。自己理解と育成計画・配属検討の基礎データに |

### 4-2. 3フェーズ×25回の配置イメージ

```
Phase 1「つながる・知る」(10〜11月・約8回) ─ 負荷: 軽
  第1回(確定): TBHの採用上の優位性を再提示——最終面接デッキ+年収デッキ(※別管理の既存資産)を
               使い「なぜTBHを選んだのは正解か」を再確認 → 各自「自分がTBHを選んだ理由」を言語化・発表
  オンライン週次: 会社を知る(創業ストーリー/ビジョン555億/ビジネスモデル)、
                  自分を知る(BQ受験・FB、入社の目的と人生の目標の言語化)、同期6名を知る
  対面日: ①キックオフ(社長講話「TBHの勝ち方」+目標発表) ②現場見学(源泉現場・施工現場)
  [採用戦力化] 自分の入社理由を1分で語れる状態に(=紹介採用の第一声)

Phase 2「TBHの考え方を身につける」(12〜1月・約9回) ─ 負荷: 中(テスト・200字報告を導入)
  オンライン週次: TBHの考え方①〜⑳(6回シリーズ)、7つの習慣(圧縮版)、
                  3つの自立、複利で成長する人間、宅建/FP・住宅ローンの基礎
  対面日: ③源泉活動体験(全員・先輩同行) ④経営方針勉強会へのゲスト参加+社員交流
  [採用戦力化] 会社説明のロープレ(説明会デッキを自分の言葉で話す練習)、28卒説明会に同席・座談会登壇

Phase 3「営業の入口・覚悟を固める」(2〜3月・約8回) ─ 負荷: 高(社内同等)
  オンライン週次: 源泉営業心得、基本のトーク(入口)、断り応酬の型、
                  1,000万逆算の数値管理、コンプライアンス
  対面日: ⑤ミニロープレ大会+実戦2回目 ⑥修了式(社長セッション+「社長への手紙」+入社前面談)
  [採用戦力化] 28卒会社説明会を内定者が自分で実施(人事同席)、紹介採用の実践(友人・後輩への声かけ)
```

**採用戦力化の縦軸**: 「語れる(Phase1)→説明できる(Phase2)→説明会を自走・紹介する(Phase3)」の3段階。
会社説明会は営業プレゼンと構造が同じ(掴み→課題→解決→クロージング)なので、**説明会の自走化=営業スキル訓練を兼ねる**。28卒採用予算(§21期計画E・800万円)の実行戦力としても機能する。

- 週次オンライン約19回+対面日6回=**25回**。対面日は月1回・終日または半日で、実戦・社長接点・同期の関係構築を集約(地方学生も月1なら参加可能)
- 各回の型: **予習動画(既存資産)→オンラインワーク→理解度テスト→200字報告→Best回答賞**。運営は導入研修・経営方針勉強会と同一フォーマット
- 教材は大半が既存(TBHの考え方スライド6本、7つの習慣動画、SEE-DO-GET90分、複利45分、基本のトーク音声、Kahoot、ゲーム型教材)。**新規制作は内定者専用の数回分+家族向け資料程度**

### 4-3. 「ゆるい採用基準」への補正機能

- 全回の出席・提出・テスト・実戦記録を**内定者カルテ**(1人1シート)に集約。BQコンポジット分析と合わせて配属・メンター選定・入社後90日プランに接続
- 提出物の質・素直さの変化を宮本チェック(Best回答賞/気になる回答)で定点観測——「入口で見極めない分、6か月かけて見極める」
- 覚悟が固まらない内定者は、修了式前の入社前面談で率直にすり合わせ(入社後の3タコ・早期離職を予防)

## 5. 家族(親ブロック)対策 ※要壁打ち

Z世代の辞退要因として親の反対は無視できない。対面日②または④に**家族向け会社説明資料**(事業の健全性・働きがいランキング7年連続・研修体制・給与実例)を配布、希望家族には社長CH動画・会社見学を案内する——を組み込むか要判断。

## 補足: 未確定の論点(壁打ちしたい残項目)

- **既存デッキの所在**: 第1回で使う「最終面接デッキ」「年収の話デッキ」(別管理)の共有(リンクまたはファイル)。内定者向けに一部改変が必要か(最終面接用=口説き文脈のままでよいか)
- **内定者の採用活動の位置づけ**: 説明会登壇・紹介活動を無償の研修内活動とするか、アルバイト給・紹介インセンティブ(SSC制度の内定者版)を設定するか

- **§3の活躍素養5つの妥当性**: トップ社員の実像・離職者の共通点と合っているか(BQコンポジット分析の知見があれば反映したい)
- **実戦の中身**: 源泉体験は「見学・同行」か「声かけまでやらせる」か(宅建業法・労務上の整理も必要——内定者アルバイト契約の形にするか)
- **報酬・拘束の扱い**: 対面日・実戦日をアルバイト給支給にするか、無償の研修とするか(拘束時間が長い場合は支給が安全)
- **講師分担**: 社長の登板回数(最低: キックオフ・修了式の2回+できれば月1)、週次オンラインの主担当(人事+若手活躍社員の輪番か)
- **経営方針勉強会へのゲスト参加**の頻度(月1で毎回混ぜるか、Phase2の1回だけか)
