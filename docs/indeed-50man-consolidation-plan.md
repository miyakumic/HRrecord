# 月給50万円一本化＋6ヶ月保証 実行計画／人材紹介との効率比較

**作成: 2026-08-17　基準データ: 採用KPIダッシュボード（13か月実績・8月累計 8/1〜8/17）**

---

## 0. 結論

1. **50万円への一本化は今週やる。ただし「原稿だけ」寄せてはいけない。** 50万で応募した人に社宅・マイカーを勧めて実質43万に戻すと辞退が出ている。原稿・面接トーク・条件通知書の3点を同時に50万へ揃えないと、一本化は辞退を増やすだけで終わる。
2. **6ヶ月保証は「コスト」ではなく「辞退を止める仕掛け」。** 会社の実負担増は1名あたり約18万円（6ヶ月合計）。1棟のインセンティブ原資が250〜500万円である事業構造からすれば、**6ヶ月で1棟決まれば回収できる**。
3. **人材紹介 vs 50万保証は「どちらか」ではない。** 6ヶ月保証はIndeedを機能させる前提条件。比較すべきは「Indeed＋50万一律・6ヶ月保証」対「人材紹介」で、**採用単価は 82万円/名 対 180〜210万円/名。約2.3〜2.6倍の差でIndeedが有利**。
4. **ただしIndeedだけでは供給量が足りない。** 一本化しても月0.9名想定。一般人材紹介を切って**20代特化エージェント（85万円/名）に付け替える**のが最適配置。

## 1. 前提の確定（2026-08-17 オーナー確認）

**有効の定義＝「有効〇」OR「1次選考を実施した人」。** これで確定。

⚠️ **ダッシュボードの自動集計を直す必要があります。** 8月Indeedの有効が、状態ボード・更新ログでは10件、数字一覧・チャネル別では6件（有効率20%）と**2つ存在**します。後者が旧定義（〇のみ）のまま。**このまま月次比較すると必ず事故ります。今週中に統一が必要。**

以下の逆算では、定義に依存しない指標（応募数・1次実施数）を軸にしています。

## 2. 逆算：月1名入社に何が必要か

**Indeed 13か月実績（2025/08〜2026/08）**

| | 実績 |
|---|---:|
| 応募 | 599件 |
| 1次実施 | 73件 |
| 入社 | 5名 |
| **応募→入社** | **120応募で1名** |
| **1次実施→入社** | **14.6件で1名** |

月1名（年12名）に必要な水準：

```
入社 1名
 ← 1次実施 14.6件
 ← 有効 29件（有効→1次が現状50%のため）
 ← 有効応募単価 × 29 = 必要月予算
```

**8月実績＝応募30・有効10・1次実施5・入社1。有効は必要29件に対し10件＝約1/3。**

## 3. 一本化するとどこまで行くか（3シナリオ）

50万水準の有効応募単価は現在 ￥22,000（43万は ￥56,011）。ただしこれは有効7件・応募12件の薄い数字で、かつ費用の50.6%がW55 1本に集中しているため、28本に広げれば平均へ戻ります。**楽観に寄せずに3本立てで見る**のが安全です。

| シナリオ | 有効応募単価 | 必要月予算（有効29件） | 採用単価/名 |
|---|---:|---:|---:|
| 楽観（50万の現数値が維持） | ￥22,000 | 64万円 | **64万円** |
| 中位（全体と50万の中間へ収束） | ￥27,000 | 78万円 | **78万円** |
| 悲観（一本化しても改善せず） | ￥32,203 | 93万円 | **93万円** |
| 参考：現状（43万・50万混在） | ￥32,203 | ― | 93万円 |

さらに **有効→1次を目標70%へ戻すと**、必要有効数が29件→20.9件に減り、楽観シナリオで**46万円/名**（目標60万円をクリア）。

**重要：上の3つのうち、悲観シナリオでも一般人材紹介（180〜210万円）の半分以下です。** つまり**この判断は楽観前提に依存していない**＝迷う理由がない。

### 4-3. 読み方

- **単価では Indeed の勝ち。一般人材紹介の 2.3〜2.6分の1。** ここは論争の余地がありません。
- **Indeed の弱点は前払いリスクと返金なし。** ただし前払いする額が64〜93万円で、紹介の180〜210万円より小さいため、**全額を捨てても紹介より安い**。リスクの絶対額で負けていない。
- **20代特化エージェント（85万円）とはほぼ互角。** ここは競合させず**両方持つ**のが正解。Indeedは前払い・供給不安定、エージェントは成功報酬・供給不安定。**性質が違うので分散になる**。
- **切るべきは一般人材紹介。** 13か月で8名を採れている実績チャネルですが、同じ8名を20代特化に付け替えれば **(180〜210万 − 85万) × 8名 ＝ 760〜1,000万円**の節減。ここが最大の金額インパクトです。

### 4-4. 6ヶ月保証の実コスト（過大に見積もらないこと）

会社が実際に負担している額で比べます。

| | 43万円プラン | 50万円プラン |
|---|---:|---:|
| 月給 | 43万円 | 50万円 |
| 家賃補助 | 4万円 | ―（対象外） |
| **会社負担 計** | **47万円** | **50万円** |
| 差額 | ― | **+3万円/月＝6ヶ月で18万円** |

**保証部分の実質コストはさらに小さい。** 現行も評価は9月末・3月末の年2回で、入社1〜6ヶ月目は立ち上がり期間として実質的に減額していません。つまり**「6ヶ月保証」は今払っている額を明文化するだけ**で、増分はほぼ紙の上の話。それで辞退が止まるなら、費用対効果は極めて高い。

⚠️ **1点だけ確認が必要（結論の符号が変わります）**
状態ボードには43万の原稿に「マイカー手当6.5万円」の記載があり、面接記録では「月額6,000円」となっています。**6.5万円が正なら 43万プランの会社負担は53.5万円＝50万プランのほうが3.5万円/月安い**ことになり、一本化は「コスト増」ではなく「コスト削減」になります。この1点は着手前に確認してください。

## 6. リスクと手当て

| リスク | 深刻度 | 手当て |
|---|---|---|
| **既存社員との不公平** | **高** | 新入社員が50万保証で、43万で入社した既存社員が据え置きだと必ず不満が出る。**先に既存社員の扱いを決めてから一本化する**。既存も50万へ揃えるのか、次回評価で調整するのかを明文化して同時に発表する。ここを後回しにすると、採用は改善しても離職が増えて差し引きマイナスになる |
| 固定残業代の計算ミス | 高 | 50万ベースで再計算・社労士確認（Phase 0-3）。43万の額を流用しない |

| Indeedの前払いリスク | 中 | 悲観シナリオでも93万円/名で紹介の半分。全額を捨てても負けない構造なので許容 |
| 有効単価が￥22,000へ収束しない | 中 | 3シナリオで判断済み。悲観でも一般紹介より安いので方針は変わらない |

## 7. 判断の型（今後これで回す）

「有意差が出るまで待つ」をやめ、**意思決定閾値**で判断します。

| 差の大きさ | 扱い |
|---|---|
| **2倍以上** | その週に決める（今回の有効単価2.5倍・紹介単価2.5倍がこれ） |
| 1.2〜2倍 | 1か月観察して決める |
| **1.2倍以内** | 誤差として何もしない（CTR差1.59ppがこれ） |

判断基準は**可逆性 × 金額**。戻せて安いものは証拠が薄くても先に動かす。原稿は前者。

壁に貼る数字は4つだけ：**月1名＝月14.6件の1次実施＝月29有効＝有効応募単価￥22,000以下**。

## 8. 一行サマリー

> 50万一本化は今週やる。ただし原稿だけでなく面接トークと条件通知書も同時に50万へ揃える（50万で釣って43万に戻す構造が辞退を生んでいる）。6ヶ月保証の実負担増は1名18万円で、辞退を止める効果に対して安い。人材紹介との比較は「Indeed＋50万保証 82万円/名 対 一般人材紹介 180〜210万円/名」で**どの前提でもIndeedが有利**。切るべきは一般人材紹介で、20代特化エージェント（85万円/名）へ付け替えれば年760〜1,000万円の節減。**最大のリスクは既存社員との不公平で、ここを先に決めてから着手すること。**
