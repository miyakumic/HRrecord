# 採用の着地予想：現行踏襲 vs 抜本改革（2案比較）

**作成**: 2026年7月
**対象**: 第21期〜第23期（2026年9月〜2029年8月）の3か年トラジェクトリ
**目的**: 「①いまの採用のまま進めた場合」と「②採用を抜本的に組み替えた場合」の着地（期末在籍・コスト・失敗の性質・棟数）を数字で並べ、意思決定の土台にする。
**根拠資料**: `docs/21ki-sales-hiring-plan.md`（第21期計画v2.0・確定値）、`docs/sales-mass-hiring-research.md`（成功事例・市場相場・損失試算の出典）

> **この文書は「予測」ではなく「前提を置いた試算モデル」です。** 太字の前提値（特に離職率・プール離脱率・配属後離職率・グロス投入数・返金条件）を変えれば着地は動きます。まずは現実の実数で前提表を上書きしてください。

## 0. 共通前提（両案で固定）

| 項目 | 値 | 出所 |
|---|---|---|
| 期首営業在籍（2026/9/1） | **25名** | 計画書・社内確認 |
| 予算上限 | **7,500万円/年** | 計画書・社内確認 |
| 棟数生産性 | **6.0棟/人・年**（新人は入社後6か月0.5人力） | 20期実績150棟÷25名 |
| 現状離職率 | **24%**（6名/25名） | 計画書・社内確認 |
| 現場早期離職1名の実損 | **約640万円**（採用費＋育成費＋機会損失） | 研究§9-1（エン・ジャパン試算） |

## 1. 結論サマリー（1分版）

- **現行踏襲（A案）**: 3年で **約51名**（46〜53名）に着地。年4,205万円で回るが、**離職24%が利得を半減させる構造**が続き、失敗（早期離職）は毎回**現場で640万円・顧客とチームと口コミを直撃**する。幹部ラインは計画に無く、内部昇格頼み。
- **抜本改革（B案）**: 3年で **約78名**に着地。年約6,000万円（上限7,500万円内）と絶対額は上がるが、**純増1名あたりは420万→315万に低下**。最大の差は金額ではなく**「失敗の場所」**——不適合を**2か月プールで1件120万円・顧客に無影響のうちに仕分ける**ため、640万円の現場離職が激減する。幹部は別財布（予備費）で2〜3名/年を確保。
- **要点**: B案は絶対コストは高いが、**同じ予算上限の中で約1.5倍の人数に着地し、1名あたりは安く、失敗を現場から引き剥がす**。「人数の失敗が無い」採用に構造を変えるのがB案。ただしプール組織の立上げ・固定費・返金条項の契約設計という**実行リスク**を負う。

## 2. A案：現行踏襲の着地予想

### 2-1. 前提（A案固有）

| 項目 | 値 |
|---|---|
| 年間採用 | 17名（21期）→以降 **16名/年**（母集団供給の上限を考慮） |
| 採用単価 | **78万円/名**（直接費） |
| 実行予算 | 約 **4,205万円/年** |
| 配属方式 | 未経験中心・**現場OJT配属**（2か月プール無し） |
| 現場離職率 | 中央 **18%**（定着投資880万で24→18に改善、ただしミスマッチが現場に残る）／感度: 15%〜24% |
| 幹部採用 | **外部ライン無し**（内部昇格頼み） |

### 2-2. 3か年トラジェクトリ（中央値：離職18%）

| 期 | 期首 | 採用 | 離職 | 期末在籍 | 棟数（目安） |
|---|---|---|---|---|---|
| 21期（〜2027/8） | 25 | +17 | ▲7 | **35名** | 約180棟（計画値） |
| 22期（〜2028/8） | 35 | +16 | ▲7 | **44名** | 約250棟 |
| 23期（〜2029/8） | 44 | +16 | ▲9 | **51名** | 約280棟 |

**感度**：離職15%達成なら23期末 **53名**／離職24%のままなら **46名**。→ **着地レンジ 46〜53名**。

### 2-3. A案の性質

- **利点**: 追加投資ゼロで既存計画のまま走れる。単価78万は全業種平均103万を下回り健全。成功報酬・無料チャネル6割で「採れなければ0円」。
- **弱点①（離職ドラッグ）**: 計画書§8が自認する通り「24%離職は採用17名の努力を半分無効化」。純増が離職に食われ続け、頭数の伸びが鈍い。
- **弱点②（失敗が現場で起きる）**: ミスマッチが現場配属後に露見するため、失敗1件が**640万円＋顧客・チーム毀損・口コミ**。早期離職を年3〜4件見込むと**年1,920〜2,560万円の価値が予算外で流出**（B/S・P/Lに現れないが実在する損失）。
- **弱点③（幹部の空白）**: 外部幹部の供給源が計画に無い。組織拡大時のマネジメント層は内部昇格のみに依存＝リスク集中。

## 3. B案：抜本改革の着地予想

### 3-1. 設計思想

**採用を2つの別システムに分離する。**

1. **量エンジン（未経験）**: 安いチャネルで広く採り、**2か月プールで育てながら仕分け**、不適合は**60%返金**でゲート費用を圧縮。失敗を現場より手前で・可逆に・安く処理する。
2. **幹部チャネル（経験者）**: プール・返金の論理が効かない領域。スカウト/DR/チーム引き抜きで**入口に厚く投資**。別財布（戦略予備費§4-F「枠外採用／M&A的リクルート」）で運用。

### 3-2. 前提（B案固有）

| 項目 | 値 |
|---|---|
| プール投入（グロス） | **30名/年**（失敗が安いので多めに試せる） |
| プール離脱率（2か月で仕分け） | **30%** → 離脱9名（実損 約120万/名） |
| 現場配属 | **21名/年** |
| 配属後・現場離職率 | **9%**（ミスマッチを事前除去＝研究§9-1「早期離職最大要因はミスマッチ57%」を潰す） |
| ゲート単価 | 85万円/名（成功報酬型）、離脱9名に60%返金 |
| プール固定費 | 専任トレーナー2〜3名 ≈ **1,500万円/年** |
| 幹部チャネル | スカウト/DR/引き抜きで **2〜3名/年**（単価約250万・予備費） |
| 実行コスト | 約 **6,000万円/年**（ゲート2,091＋プール1,500＋定着/SNS/体制1,800＋幹部600・**上限7,500内**） |

### 3-3. プール失敗1件の原価（返金の本質はここ）

| 失敗の場所 | 1人あたり損失 |
|---|---|
| 現場に出してから離職（A案の失敗） | **約640万円** |
| プール2か月で仕分け（B案の失敗） | **約120万円**（2か月給与50〜60万＋研修工数＋返金後の実質報酬30万強） |

→ **B案は640万の失敗を120万に変える。** 返金60%は「戻る報酬部分」を担う脇役で、主役は**失敗地点を現場より手前に移すこと**。

### 3-4. 3か年トラジェクトリ（配属後離職9%）

| 期 | 期首 | 配属＋幹部 | 離職 | 期末在籍 | 棟数（目安） |
|---|---|---|---|---|---|
| 21期（〜2027/8） | 25 | +23（配属21＋幹部2） | ▲4 | **44名** | 約200棟 |
| 22期（〜2028/8） | 44 | +23 | ▲5 | **62名** | 約350棟 |
| 23期（〜2029/8） | 62 | +23 | ▲6 | **79名** | 約460棟 |

※21期は移行・立上げ期のため、実務上は40〜44名の下振れ幅を見込む。

### 3-5. B案の性質

- **利点①（人数の確実性）**: プールが頭数を保証し、失敗が可逆。「9月末までに◯名」を**採用数の失敗なしで**狙える。
- **利点②（1名あたりが安い）**: 純増1名あたり**約315万**（A案420万＋予算外の現場離職損失）。**絶対額は上がるが効率は上がる**。
- **利点③（ブランドを守る）**: 失敗がプール内＝OpenWork・転職会議・顧客に出ない。計画書がSNS・口コミで築くブランド（§6・§8）を自壊させない（＝光通信型の回避／研究§10-6）。
- **利点④（幹部の別建て）**: 幹部を安く採ろうとして組織を壊す事故を構造的に防ぐ。
- **リスク①**: **プール組織の立上げと固定費**（トレーナー2〜3名・カリキュラム・場所）。管理工数も増える。
- **リスク②**: **返金条項の契約設計**。60%返金が「本人退職」条件か「会社都合の見送り」でも効くかを要確認。日本の試用期間解雇は完全自由ではない点も留意。
- **リスク③**: **配属が2か月遅れる**（時間コスト）。立上げ期の棟数は一時的に下振れ。

## 4. 2案の並置比較（3か年着地・23期末）

| 指標 | A案：現行踏襲 | B案：抜本改革 |
|---|---|---|
| **期末在籍（23期）** | 約 **51名**（46〜53） | 約 **79名** |
| 3年純増 | +26名 | +54名 |
| 年間実行コスト | 約4,205万円 | 約6,000万円（上限7,500内） |
| 3年累計コスト | 約1.26億円 | 約1.8億円 |
| **純増1名あたり** | 約 **420万円** ＋予算外の現場離職損失 | 約 **315万円** |
| **失敗の発生場所** | **現場**（1件640万・顧客/チーム/口コミ直撃） | **プール**（1件120万・顧客に無影響・可逆） |
| 幹部ライン | **無**（内部昇格頼み） | 別財布で2〜3名/年 |
| 人数目標の達成確実性 | 離職24%が利得を半減させるリスク | プールが頭数を保証、失敗が可逆 |
| 棟数（23期・目安） | 約280棟 | 約460棟 |
| 主なリスク | 離職ドラッグ／母集団供給の頭打ち | プール固定費・立上げ／返金契約設計／配属2か月遅れ |

## 5. 判断ポイント（このモデルで意思決定するために埋める空欄）

1. **人数目標の確定**: 3年で50名級（A案）か、75〜80名級（B案）か。**受け皿（ポスト・棟数）が先にあるか**が前提（研究§4-1オープンハウスの教訓＝ポストを先に作る）。
2. **プール前提の実測**: 「プール離脱率30%」「配属後離職9%」は仮置き。過去の未経験入社の実データで補正すると精度が跳ねる。
3. **幹部の設計**: 何名を・いつ・どこから（内部昇格／外部スカウト／チーム引き抜き）。ここがA案の空白であり、B案の差別化点。
4. **返金条項の交渉**: 60%返金のトリガー（退職か会社都合か）・期間（2か月か）・原資（報酬のみか）を紹介会社と契約前に確定。
5. **移行の可否**: B案はプール組織という固定費・立上げを負う。予備費3,295万円の一部をこの立上げに充てる判断。

---

## 6. 一行の要約

**A案は「安く回るが離職に食われ、失敗が現場を痛める」。B案は「絶対額は上がるが、同じ予算内で1.5倍の人数に着地し、1名あたりは安く、失敗をプールに閉じ込める」。** 分岐点はコストではなく、**失敗をどこで起こすか（現場か、プールか）**と、**幹部を量と同じ財布で採るか、別建てにするか**。
