# 採用の着地予想：2027年10月1日・純在籍55名に向けて

**作成**: 2026年7月
**目標**: **2027年10月1日時点で営業純在籍55名**（現状25名 → 純増+30、逆算約13か月）
**論点**: いまの採用のまま進めた場合の着地と、抜本的に組み替えた場合の着地を数字で並べる。
**根拠資料**: `docs/21ki-sales-hiring-plan.md`（第21期計画v2.0・確定値）、`docs/sales-mass-hiring-research.md`（市場相場・損失試算の出典）

> **この文書は「予測」ではなく「前提を置いた試算モデル」です。** 太字の前提値（離職率・プール離脱率・配属後離職率・グロス投入数・返金条件）を実データで上書きすれば着地は動きます。

---

| 項目 | 値 | 出所 |
|---|---|---|
| 期首営業在籍（2026/9/1） | **25名** | 計画書 |
| 目標（2027/10/1・純在籍） | **55名**（純増+30） | 経営方針 |
| 逆算期間 | 約13か月 | ― |
| 予算上限 | **7,500万円** | 計画書 |
| 現状離職率 | **24%** | 計画書 |

| 棟数生産性 | 6.0棟/人・年（新人は6か月0.5人力） | 20期実績 |

## 1. 結論サマリー（1分版）

- **現行踏襲（A案）は55名に届かない。** 計画通り17名採用しても、24%離職に食われて **着地は35名**。目標に **▲20名** 足りない。これは努力不足ではなく、**現行モデルの構造上限**（計画書§8「24%離職は採用17名の努力を半分無効化」）。
- **現行モデルのまま55名を狙う（A'案）と「汚く」しか届かない。** 離職を織り込むとグロス41名を採る必要があり、失敗が**現場で640万円ずつ**発生。名目6,078万でも**真の総負担は約1億円**、しかも高離職の口コミでブランドが傷つく（＝光通信型／研究§10-6の回避対象そのもの）。
- **抜本改革（B案）は55名に「設計で」届く。** 2か月プール＋60%返金＋幹部分離で、**着地55〜56名**。総コスト約7,416万（上限7,500内）、**純増1名あたり239万**。最大の差は、失敗を**プール内で1件120万・顧客に無影響・可逆**のうちに仕分ける点。
- **要点**: 55名という目標を置いた瞬間、勝負は「採用を頑張るか」ではなく **「現行モデルの構造上限を、組み替えで超えるか」** になる。A案では届かず、A'案は割高＆ブランド毀損、**B案だけが上限予算内でクリーンに55名に着地する**。

---

## 2. A案：現行踏襲の着地予想 → **35名（▲20名未達）**

| 項目 | 値 |
|---|---|
| 年間採用 | 17名（計画通り） |
| 離職 | ▲7名（28%保守／目標15%でも▲4名） |
| 単価 | 78万円/名 |
| 実行予算 | 約4,205万円 |
| **2027/10/1 着地** | **約35名** |

**25 ＋ 17 − 7 ＝ 35名。** 目標55名に対し **▲20名**。
現行計画は「35名体制で180棟」を狙う設計であり、そもそも55名を想定していない。**A案は"堅実だが目標未達"が確定路線。**

---

## 3. A'案：現行モデルのまま無理やり55名 → **届くが「汚い」**

「じゃあもっと採ればいい」を数字にすると、現行モデルの弱点が露呈する。

| 項目 | 値 |
|---|---|
| 必要グロス採用 | **約41名**（24%離職を織り込むと純増30に41採用が必要） |
| 期中離職 | 約11名（大半が**現場で**発生） |
| 早期離職の実損 | 約6名 × 640万 ≈ **3,840万円**（予算外流出） |
| 名目コスト | 採用41×78万＝3,198万 ＋ 定着/SNS/体制 2,880万 ≈ **6,078万円** |
| **真の総負担** | 名目6,078万 ＋ 隠れ損3,840万 ≈ **約9,900万円** |
| ブランド | 高離職がOpenWork・転職会議に蓄積 → 母集団形成が崩れる |

**着地は55名に届くが、真の負担は約1億円、かつブランド毀損。** 予算上限7,500万を隠れ損込みで実質超過する。**「頭数は埋まるが会社が痛む」——研究§10-6が名指しで却下した光通信型そのもの。**

---

## 4. B案：抜本改革の着地予想 → **55〜56名を設計で達成**

### 4-1. 設計：採用を2システムに分離

1. **量エンジン（未経験）**: 安いチャネルで広く採り、**2か月プールで育てながら仕分け**、不適合は**60%返金**でゲート費用を圧縮。失敗を現場より手前で・可逆に・安く処理。
2. **幹部チャネル（経験者）**: プール・返金が効かない領域。スカウト/DR/チーム引き抜きで**入口に厚く**。別財布（予備費§4-F）。

### 4-2. 前提と逆算

| 項目 | 値 |
|---|---|
| プール投入（グロス・期中） | **48名**（8〜10名×約5波のコホート） |
| プール離脱率（2か月で仕分け） | 30% → 離脱**14名**（実損120万/名） |
| 現場配属 | **34名** |
| 配属後・現場離職 | 9%（按分）→ 約2名 |
| 既存25名の離職 | 15%（プール由来の新戦力で組織安定化）→ 約4名 |
| 幹部チャネル | **+3名**（別財布・単価約250万） |
| **2027/10/1 着地** | **25 − 4 ＋ 34 − 2 ＋ 3 ＝ 56名** ✓ |

### 4-3. コスト（単期）

| 区分 | 金額 |
|---|---|
| ゲート（48×85万 − 返金14×51万） | 3,366万円 |
| プール固定費（専任トレーナー2〜3名） | 1,500万円 |
| 定着・SNS・体制 | 1,800万円 |
| 幹部チャネル（3名・予備費） | 750万円 |
| **合計** | **約7,416万円**（上限7,500内） |
| 純増1名あたり | **約239万円** |

### 4-4. 失敗の原価（返金の本質）

| 失敗の場所 | 1人あたり | 件数 | 合計 |
|---|---|---|---|
| 現場に出してから離職（A'案） | 640万円 | 約6件 | 約3,840万円（顧客・ブランド直撃） |
| プール2か月で仕分け（B案） | 120万円 | 14件 | 約1,680万円（顧客に無影響・可逆） |

**B案は失敗の総額も件数あたりも小さく、しかも現場から引き剥がしている。** 返金60%は報酬部分を戻す脇役で、主役は**失敗地点をプールに移すこと**。

### 4-5. タイムライン制約（要注意）

2か月プールには**配属までのラグ**がある。55名を2027/10/1に揃えるには——
- **2026/9に第1波を投入 → 11月配属**、以降ほぼ毎月コホートを回す
- **最終波の投入は2027/7まで**（2か月プール→9月配属→10/1在籍に間に合う）
- ゲートは月4〜5名の投入ペース。計画書の複線チャネル（成功報酬20代＋自衛官＋リファラル＋求人広告）で供給する

→ **B案は今すぐ動き出さないと13か月に間に合わない。** 立上げ判断が最大の時間リスク。

## 6. 判断ポイント

1. **A案は55名という目標とそもそも整合しない**（35名設計）。55名を本気で置くなら、A案は選択肢から外れる。
2. **A'案（現行モデルで数だけ増やす）は最悪手**。真の負担が最大でブランドも痛む。「採用を頑張る」の落とし穴。
3. **B案の成否は3つの前提**に依存 —— ①プール離脱率30%・配属後離職9%（過去の未経験入社の実データで補正必須）、②60%返金のトリガー（退職か会社都合か）と原資、③**今すぐ立ち上げられるか**（13か月の時間制約）。
4. **幹部3名の供給源を確定**（内部昇格／外部スカウト／チーム引き抜き）。B案の差別化点であり、A案の空白。
5. **予算**: B案は上限7,500万をほぼ使い切る（予備費3,295万の相当部分をプール立上げ・幹部に充当）。これを許容するかの経営判断。

---

## 7. 一行の要約

**55名を2027/10/1に置いた瞬間、現行計画（35名設計）は届かない。数だけ増やせば真の負担は約1億＋ブランド毀損。届かせるには、失敗をプールに閉じ込め幹部を別建てにするB案しかなく、それは上限予算内・純増1名239万で成立する——ただし今すぐ立ち上げる場合に限る。**
