## 1. 目的

- **楽しく盛り上げて、必読書を読む習慣をつける**（今回いちばん重視する目的）
- 社員の中に「読んだ人」と「まだ読んでいない人」が混ざっている前提で、**読むきっかけ**をつくる
- 既存のチーム・ユニット単位で戦うことで、**リーダーが部下に読ませる・教える動き**を準備期間中に引き出す

## 2. 必読図書と出題範囲

| 階層 | 対象の本 | 出題範囲 |
|---|---|---|

## 3. ゲームの設計方針

- **チームは既存の課・部署単位**（シャッフルしない）。「自分のチームで良い点を取りたい」と思ったリーダーが、準備段階で部下に働きかけることをねらう
- 3名以下の課は**合体チーム**にして、各チーム5〜8名にそろえる
- **一人ひとりが「自分の階層の問題」に答える**（誰かに代わりに答えてもらうことはできない）
- 人数差・階層構成の差が出ないよう、**合計点ではなく正答率（平均・最低点）で比べる**
- 道具は**紙とホワイトボード**のみ（スマホ・PCは使わない）

## 4. 点数のしくみ（100点満点）

| 項目 | 配点 | 計算方法 | リーダーに求められること |
|---|---|---|---|
| 平均点 | 50点 | チーム全員の正答率の平均 × 50 | 全員に読ませる |
| 底上げ点 | 25点 | **チーム内で一番低い人の正答率 × 25** | 誰も置いていかない |
| ケース点 | 25点 | 「この場面、どの本？」にチームで回答。**発表はリーダー以外が行う** | 部下が自分の言葉で説明できるように育てる |

- 準備点（事前の読書シェア会での加点）は**採用しない**（告知しない点数を当日加えるのは不公平になるため）
- リーダー自身が答えて点を稼げる構造ではなく、**部下に関わらないと点が伸びない**構造にしている

## 5. 当日の流れ（40分）

| 時間 | 内容 | 形式 |
|---|---|---|
| 0〜3分 | オープニング（目的・ルール説明） | 司会 |

| 38〜40分 | 表彰・菊田社長の講評 | 司会 |

## 6. 問題例

### 6-1. ○×クイズ（肩慣らし）

| 問題 | 答え |
|---|---|
| 鬼速PDCAの「A」は「行動」ではなく「調整」である | ○ |
| 『人を動かす』では、議論に勝つ最善の方法は相手を論破することだ | ×（議論を避けること） |
| 7つの習慣の第1の習慣は「主体的である」 | ○ |
| 飛躍した企業は、先に目標を決めてから人を選んだ | ×（最初に人を選ぶ） |
| 『ザ・ゴール』では、企業の目的は「お金を儲けること」 | ○ |

### 6-2. 階層別個人戦（問題例）

| 階層 | 問題例 → 答え |
|---|---|
| 新入社員 | KGI→KPI→？ → **KDI** ／ 目標を細かく分けることを本では何と言う？ → **因数分解** ／ その人にとって最も快い響きの言葉は？ → **名前** |
| 一般社員 | 「緊急ではないが重要」な領域は第何領域？ → **第2領域** ／ 第5の習慣「まず○○に徹し、そして○○される」 → **理解** ／ 主体的な人が力を注ぐのは「関心の輪」と「影響の輪」のどちら？ → **影響の輪** |
| リーダー | 針鼠の概念の3つの円は？ → **情熱をもって取り組めるもの／世界一になれる部分／経済的原動力** ／ 「何をするか」より先に「誰を○○に乗せるか」 → **バス** ／ 第五水準のリーダーは成功時は○、失敗時は○を見る → **窓（の外）／鏡** |
| 課長以上 | ハイキングで一番遅いハービーは何の象徴？ → **ボトルネック** ／ 3つの指標は？ → **スループット・在庫・業務費用** ／ ボトルネックでない工程で1時間短縮すると全体は？ → **何も変わらない** |

> 出題担当は、本番前に**本のどのページに答えがあるかを確認**すること（担当者自身の学びにもなる）。

### 6-3. ケース問題「この場面、どの本？」

| 場面 | 答え（本と原則） |
|---|---|
| 新人営業が毎日頑張って電話しているのに、アポイントが取れない | ①鬼速PDCA（因数分解・KDI） |
| お客様に値引きを迫られて、つい自分たちの正しさを主張してしまう | ②人を動かす（議論を避ける・相手の立場に立つ） |
| クレーム対応に追われて、資格の勉強が進まない | ③7つの習慣（第2領域） |
| 新しい施策を次々に打っているが、チームの成果が安定しない | ④ビジョナリー・カンパニー2（針鼠の概念・弾み車） |
| 契約は取れているのに着工が遅れ、引き渡しが詰まっている。それでも営業はさらに契約を増やそうとしている | ⑤ザ・ゴール（ボトルネックに集中する） |

## 10. 決定事項の経緯

| 論点 | 当初案 | 決定 | 理由 |
|---|---|---|---|
| チーム編成 | 階層をまぜたシャッフルチーム | **既存の課・部署単位** | 準備段階でリーダーが部下に働きかける動きを引き出すため |
| 小さい課 | 課ごとに単独参加 | **合体チーム**で5〜8名にそろえる | 人数をおおむね同じにするため |
| 新入社員枠 | 研修生のみ | **研修生＋入社1年以内の中途** | 必読書①の対象を実態に合わせるため |
| 準備点 | 読書シェア会1回5点 | **採用しない** | 告知に入れないため、ルールからも外した |
| チーム分けの公開 | 当日発表 | **事前に告知文で公開** | 準備期間中にチームで動いてもらうため |
| 告知の送り方 | 11/2 予約投稿 | **宮本が手動で早めに投稿** | ー |
